# Análise de Consumo de Energia

Projeto de análise de dados com foco na identificação de padrões de consumo de energia elétrica e oportunidades de otimização de custos.

## Objetivo
Analisar o comportamento do consumo ao longo do tempo e identificar períodos de maior gasto energético.

## Dados
- Consumo mensal (kWh)
- Valor da fatura

## Ferramentas
- Python
- Pandas
- Matplotlib

## Etapas
- Coleta e organização dos dados
- Tratamento de dados
- Análise exploratória
- Visualização de dados

## Insights
- Identificação de meses com maior consumo
- Relação entre consumo e valor da fatura
- Tendência de crescimento ou redução de consumo
